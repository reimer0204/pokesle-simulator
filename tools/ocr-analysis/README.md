# OCR解析チューニングツール

`test/ocr` に置いたサンプル画像をまとめて解析し、CSVへ出力するための開発専用画面です。
この画面は本番アプリのルーターやビルド入口から参照されないため、通常の `npm run build` の成果物には含まれません。

## 使い方

1. `test/ocr` に解析対象の画像を置きます。
2. `npm run dev:ocr` を実行します。
3. 開いた画面で「全画像を解析」を押します。
4. 完了後に「CSVをダウンロード」を押します。
5. 出力された解析結果を `test/ocr/ocr-analysis-results.csv` の期待値列と比較します。

期待値を追加・修正する場合は、解析結果側と同じ列順でCSVの期待値欄を更新してください。
